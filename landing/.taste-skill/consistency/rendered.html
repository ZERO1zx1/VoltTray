AirPods бүрэлдэхүүнийг салгаж харуулна

Linux дээр kAirPods ажиллаж байвал зүүн, баруун, кейс болон AirPods Max-ийн бүрэлдэхүүнийг тусад нь харуулна.

kAirPods service ажиллаж, хэрэглэгчийн session D-Bus-д хандах боломжтой байх шаардлагатай.

Төхөөрөмжийн уншилт таны компьютер дээр үлдэнэ. Аккаунт байхгүй, гадаад сервер байхгүй, cloud sync байхгүй.

Эх кодоос гурван алхмаар

Бэлэн суулгагч байхгүй. Эх кодыг GitHub-аас авч, Node.js 20.19+ эсвэл 22.12+, npm, Rust stable болон Tauri build орчинтойгоор ажиллуулна.

1

Эх код авах

Нийтийн репозитороос кодыг татна.

git clone https://github.com/ZERO1zx1/VoltTray.git
2

Хамаарал суулгах

Төслийн хавтас руу орж npm хамаарлуудыг суулгана.

cd VoltTray
npm ci
3

Ажиллуулах эсвэл build хийх

Хөгжүүлэлтийн горим эсвэл release bundle үүсгэнэ.

npm run tauri:dev
npm run tauri:build

Мэдээлэл машин дотроо үлдэнэ

VoltTray нь төхөөрөмжийн уншилт болон тохиргоог локал орчинд ашиглана. Аккаунт үүсгэх, cloud sync хийх, гадаад серверт илгээх шаардлагагүй.

Апп нь холболтын сүлжээгүй үед ч үндсэн уншилтуудыг локал байдлаар харуулах зорилготой. Зарим нэмэлт боломж, жишээ нь Linux дээрх AirPods бүрэлдэхүүн, тухайн орчны локал service-ээс хамаарна.

Түгээмэл асуулт

Бэлэн суулгагч байгаа юу?

Одоогоор бэлэн суулгагч нийтлэгдээгүй. Эх кодыг GitHub-аас авч, npm ci дараа нь npm run tauri:dev эсвэл npm run tauri:build командыг ажиллуулж болно.

AirPods яаж харагддаг вэ?

Linux дээр kAirPods service ажиллаж, хэрэглэгчийн session D-Bus-д хандах боломжтой үед зүүн, баруун, кейс болон AirPods Max-ийн бүрэлдэхүүнийг тусад нь харуулна. Энэ нь kAirPods-ийн суулгалт, pairing эсвэл тохиргоог VoltTray хийх гэсэн үг биш.

Тоглоомын үеийн сэрэмжлүүлэг яадаг вэ?

Мэдэгдлийн дүрэмд бүтэн дэлгэцийн нөхцөлтэй холбоотой сонголт байна. Тохиргооноос хамаарч тост мэдэгдлийг харуулах эсвэл түр дарангуйлах боломжтой.

Виджет нуугдсан үед сэрэмжлүүлэг ажиллах уу?

Сэрэмжлүүлэг нь виджетийн snapshot өгөгдөл боловсруулах үед гарна. Хэрэв виджет нуугдсан эсвэл өгөгдөл шинэчлэгдэхгүй байвал зарим мэдэгдэл хоцрох, гарахгүй байж болно.

Өгөгдөл хаана хадгалагддаг вэ?

Төхөөрөмжийн уншилт болон тохиргоо таны компьютерийн локал орчинд ашиглагдана. Аккаунт, cloud sync, гадаад сервер шаардлагагүй.

Лицензийн нөхцөл ямар вэ?

Эх код GitHub дээр нээлттэй харагдаж байгаа ч репозиторт LICENSE файл заагаагүй байна. Тиймээс энэ хуудсанд тодорхой нээлттэй эхийн лиценз байна гэж бичээгүй.
